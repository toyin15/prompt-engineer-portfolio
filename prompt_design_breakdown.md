## 🎯 Prompt Objective

This prompt is designed to help creators generate clear, structured YouTube scripts that follow a consistent and engaging narrative arc: Hook → Talking Points → Outro.

Ideal for:
- Creators with writer’s block
- Teams needing consistent structure across videos
- Generative AI use in batch scripting workflows

---

## 🧾 Original Prompt

```text
You are a YouTube scriptwriter.

Create a 3-minute YouTube script with a hook, 3 main talking points, and a brief outro on the topic: “Why Gen Z Loves Silent Vlogging.”

Make it casual, concise, and formatted like a script outline with talking point bullets.
```

---

## 🧪 Prompt Structure Breakdown

| Section        | Purpose |
|----------------|---------|
| `You are a YouTube scriptwriter.` | Establishes role/persona to guide voice and tone |
| `Create a 3-minute YouTube script...` | Defines output format and time constraint |
| `Hook → 3 points → Outro` | Gives structural expectation |
| `Topic: Why Gen Z Loves Silent Vlogging` | Injects creative subject for testing |
| `Casual, concise, outline format` | Controls tone, length, and delivery style |

## 🧠 Lessons Learned

- Claude tends to outperform GPT-4 in casual tone + cultural fluency
- Prompt structure clarity (e.g., “use bullets”) significantly improves output format
- Adding “voice” guidance reduces post-editing time by ~40%
