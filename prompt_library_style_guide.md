## 🎯 Purpose

This guide helps AI and content teams maintain consistency, clarity, and performance across all prompt design efforts. It covers naming conventions, formatting best practices, prompt personas, and model-specific tips.

---

## 🔤 Prompt Naming Conventions

| Prompt Type        | Format Example                      | Notes |
|--------------------|--------------------------------------|-------|
| Ideation           | `video_hook_gen_z_vibes`            | Use lowercase + underscores |
| Summarization      | `reddit_to_summary_3_points`        | Start with source or goal |
| Scriptwriting      | `yt_script_outline_productivity`    | Be specific about platform or voice |
| Editing/Tone       | `tone_shift_professional_to_genz`   | Clearly state transformation |
| Persona            | `roleplay_brand_strategist_blog`    | Use `roleplay_` prefix for clarity |

---

## 📐 Prompt Formatting Standards

| Element              | Best Practice |
|----------------------|----------------|
| Instructions         | Use natural language, direct tone |
| Role/Persona         | Start with “You are a…” to guide tone |
| Output Structure     | Include format expectations: “use bullets,” “3 points,” etc. |
| Length Guidance      | Specify if needed: “3-minute script,” “under 200 words” |
| Optional Elements    | Add “Use emojis if helpful,” or “Speak in TikTok tone” as modifiers |

## 🧑‍🎤 Common Prompt Personas

| Persona Name        | Description |
|---------------------|-------------|
| YouTube Scriptwriter| Great for generating story-based or structured content |
| Brand Strategist    | Ideal for social media captions, brand tone consistency |
| Content Editor      | For rewriting, polishing, or tone-shifting |
| Data Analyst        | Used when summarizing technical outputs or datasets |
| Career Coach        | Great for resume feedback, personal bios, or cover letters |

## 🤖 Model-Specific Tips

| Model     | Strengths | Cautions |
|-----------|-----------|----------|
| GPT-4     | Excellent with structure and length control | Can be formal by default; add tone cues |
| Claude 3  | Strong at casual tone and soft nuance | Sometimes over-apologizes or over-hedges |
| Gemini    | Great at factual tasks | Weak with creativity or cultural references |

---

## 🔁 Team Prompt Review Process

1. Submit prompts via shared Notion or GitHub vault
2. Test across at least 2 LLMs if multi-platform
3. Record outputs + score based on clarity, structure, and tone match
4. Log edits and prompt improvements (version tracking encouraged)
5. Archive retired prompts with reason

---

## 📂 Vault Maintenance Tips

- Group prompts by outcome, not just format (e.g. “Increase engagement” vs “Scriptwriting”)
- Use tags like `#longform`, `#persona`, `#slang`, `#customer-facing`
- Set calendar reminders to prune unused or low-performing prompts every quarter
