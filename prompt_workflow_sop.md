## 🎯 Objective

This SOP outlines a repeatable process for using Large Language Models (LLMs) to generate, refine, and deploy content across formats such as YouTube scripts, social media captions, blog posts, and summaries.

It is intended for solo creators, content ops teams, and AI product writers leveraging GPT-4, Claude, or Gemini for ideation and production.

---

## 🧾 Workflow Overview

### Step 1: Input Collection

Gather the following details before prompting:
- 🎯 Topic or Idea (e.g., “Why Gen Z Loves Silent Vlogging”)
- 👥 Target Audience (e.g., Gen Z, Professionals)
- 📍 Platform (YouTube, Blog, IG, LinkedIn)
- 🎙️ Tone / Brand Voice (e.g., casual, witty, professional)
- 🧨 Content Goal (clicks, shares, conversions, retention)

---

### Step 2: Prompt Selection (from Vault)

Choose a tested prompt based on outcome:
| Goal | Prompt Type |
|------|-------------|
| Grab attention | Hook Generator |
| Build a full piece | 3-Part Script Builder |
| Summarize research | Reddit Summarizer / TL;DR |
| Reformat tone | Tone Shifter |
| Repurpose across platforms | Format Adaptation Prompt |

---

### Step 3: LLM Selection

| Model | Best For |
|-------|----------|
| **Claude 3** | Gen Z tone, TikTok/casual, soft nuance |
| **GPT-4** | Long-form structure, professional tone |
| **Gemini** | Factual summaries, quick metadata or bullet lists |

---

### Step 4: Prompt Execution

- Paste prompt into your preferred LLM (Claude, GPT-4, Gemini)
- Include context: brand tone, audience, format
- Run 2–3 iterations if needed
- Score outputs based on:
  - ✅ Tone Match
  - ✅ Hook Strength
  - ✅ Output Structure
  - ✅ CTA Effectiveness (if applicable)

---

### Step 5: Post-Processing

- Edit draft manually or use Tone Shifter prompt for polishing
- Add platform-specific tweaks (hashtags, emojis, etc.)
- Final QA: Check for hallucinations, length, voice

---

### Step 6: Repurpose or Archive

- Save strong outputs into Notion or a prompt vault
- Tag with outcome type and model used
- Archive underperforming prompts with notes

---

## 🔁 Notes

- Run a weekly or monthly prompt review to refine performance
- Track which prompts yield high-performing content
- Consider using Loom to document top prompt→output flows

---

## 🧂 Bonus Prompt Add-Ons

| Modifier | Purpose |
|----------|---------|
| “Use slang if appropriate” | Improves relatability for younger audiences |
| “Write in TikTok voiceover tone” | Adds scroll-stopper energy |
| “Use emoji where helpful” | Adds visual texture on social platforms |
| “Make it 200 words or less” | Optimizes for caption-based formats |
